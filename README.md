# Healthcare Facility & Patient Management System (HF-PMS)

## Project Overview

The Healthcare Facility & Patient Management System (HF-PMS) is an AI and Data Analytics-based healthcare project developed as part of the Summer Internship Program. The project focuses on analyzing healthcare and pharmaceutical datasets to extract meaningful insights, evaluate treatment effectiveness, and predict patient outcomes using Machine Learning techniques.

The project combines Data Analytics, Exploratory Data Analysis (EDA), KPI Analysis, Data Preprocessing, and Support Vector Machine (SVM) based predictive modeling to support data-driven healthcare decision-making.

---

## Project Objectives

- Understand healthcare datasets and patient records.
- Perform data cleaning and preprocessing.
- Conduct Exploratory Data Analysis (EDA).
- Generate healthcare Key Performance Indicators (KPIs).
- Analyze pharmaceutical treatment effectiveness.
- Develop Machine Learning models.
- Predict patient treatment outcomes.
- Evaluate model performance using standard metrics.
