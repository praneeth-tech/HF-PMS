# Healthcare Facility & Patient Management System

## Project Overview

This project focuses on analyzing healthcare and patient data using the Diabetes Dataset.

The objective is to understand patient health conditions, identify diabetes-related factors, and generate useful insights through Exploratory Data Analysis (EDA).

---

## Dataset

Source:
https://www.kaggle.com/datasets/brandao/diabetes
